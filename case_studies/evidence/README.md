# Retained paper evidence

These records are historical measurements, not fresh checks of the reorganized
compiler. Their bytes are preserved in `origins.json`. Paths embedded in records
refer to the original tree inside the archive identified by `../history.json`.

| Record | Scope |
| --- | --- |
| `linux/*.json` | Six manifests covering 25 paired units and 50 successful backend invocations |
| `historical-compatibility.json` | All ten original scoped verdicts, including counterexamples and failures |
| `record-compatibility.json` | Later SGLang/PyTorch unchanged-body record comparisons |
| `functional-portfolio.json` | Ten-project functional and native-integration portfolio |
| `maintenance-results.md` | Controlled authored-change maintenance study |
| `library-diagnostic.json` | Separate public-library information diagnostic |
| `calendar-search.md` | Frozen search retaining its empty eligible cohort |
| `completion-audit.md` | Review authority, exposure and remaining transfer limitations |
| `sglang-runtime.json` | GPU runtime analysis for the recorded workload and hardware |

The normalized inputs for the paper's maintenance tables already live in
`paper/evidence/maintenance-metric-inputs.json`. They are retained there instead
of being copied here. Paper table and figure generators use these compact inputs.
Raw transcript collection requires the extracted historical archive.

All old failures, rejected requirements, original review decisions and alternative
attempts are retained in the complete archive. Removing their working directories
does not remove them from the research record or change experiment denominators.
